# Library Management System

A **menu-driven C++ console application** to manage library records with CRUD operations.

## Features
- Add, display, search, update, and delete book records
- Handles **100+ books** using structures and arrays
- Modular design with **5+ reusable functions**
- User-friendly menu interface for smooth interaction

## Technologies
- C++
- Structured Programming
- Arrays & Structures
- Modular Functions

## How to Run
1. Clone the repository or download the files.
2. Open terminal/command prompt in the project folder.
3. Compile the project:
   ```bash
   g++ LibraryManagementSystem.cpp -o library
